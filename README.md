# Hobby ARPG (рабочее название)

Личный хобби-проект: диаблоид ARPG + рогалик. Гринд мобов → лучшая экипировка → гринд мобов сильнее.
Без планов на релиз, главная цель — получать удовольствие от разработки и свободно экспериментировать.

- **Движок:** Unity 6 LTS, URP, C#
- **Стиль:** лоуполи / мультяшное 3D (референсы: Darksiders Genesis, Shape of Dreams)
- **Камера:** top-down, WASD + прицел и взаимодействие мышью
- **Мир:** открытые зоны + процедурные данжи
- **Прогрессия:** лут и тайник сохраняются между забегами

## Быстрый старт

```bash
git lfs install
git clone <url-репозитория>
```

Открыть папку `Game/` через Unity Hub (Unity 6 LTS). Подробнее: [docs/07-git-workflow.md](docs/07-git-workflow.md).

## Структура репозитория

```
/
├── docs/            документация проекта
├── Game/            Unity-проект (создаётся на этапе 0 роадмапа)
├── Art/             исходники: .blend, .psd, референсы (через LFS)
├── Tools/           скрипты вне Unity (валидация JSON, экспорт и т.п.)
├── .gitattributes   правила Git LFS и merge для Unity YAML
├── .gitignore       Unity + Blender + IDE
└── .editorconfig    стиль кода C#
```
