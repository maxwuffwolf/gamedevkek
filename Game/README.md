# Game — Unity-проект

Unity **6000.6.10f1**, URP, Input System. Настройки проекта взяты из шаблона *Universal 3D* этой версии редактора.

## Как открыть

1. Unity Hub → **Add → Add project from disk** → выбрать папку `Game` в клоне репозитория.
2. Первое открытие займёт несколько минут (импорт пакетов).
3. При первом открытии скрипт сам соберёт сцену `Assets/_Project/Scenes/Showcase.unity` и откроет её.
   Если этого не произошло: меню **Game → Открыть сцену Showcase**.
4. Нажать **Play**.

## Что проверить в шоукейсе

| Что | Как |
|---|---|
| Движение и прицел | WASD, персонаж бьёт туда, где курсор |
| Базовая атака | ЛКМ (можно зажать) |
| Навык «Тяжёлый удар» | клавиша **1** (мана 18, перезарядка 4 с) — панель из 12 слотов внизу |
| HP / мана | столбики слева и справа от панели навыков |
| Квест | подойти к Торвальду с «!» у костра, кликнуть → диалог → «Берусь» |
| Волки | к северу от лагеря, слева и справа от тропы |
| Лут | трупы растворяются, остаётся луч цвета самой редкой вещи; клик по лучу → в рюкзак |
| Инвентарь | **B**: слева экипировка, справа рюкзак (12 из 40 ячеек открыто). ПКМ — надеть/снять, перетаскивание |
| Сдать квест | «?» над Торвальдом → награда + 8 ячеек рюкзака → следующий квест «Вожак стаи» |
| Сохранение | выйти из Play и зайти снова: экипировка, рюкзак и квесты на месте |

## Инструменты разработчика

| Клавиша | Что |
|---|---|
| **`** (Ё) | Дев-консоль: `help`, `give hood_wolf epic`, `spawn wolf 5 3`, `god`, `killall`, `loot.sim wolf 1000`, `save.wipe` … Tab — автодополнение |
| **F1** | Чит-меню: god, спавн мобов, выдача предметов, сброс квестов, новая игра |
| **F3** | FPS и сводка |
| **F5** | Перечитать JSON из `Assets/StreamingAssets/Data` (сохранение JSON-файла тоже подхватывается автоматически) |

Меню **Game** в редакторе: пересобрать сцену, открыть папку данных/сохранений, удалить сохранение.

Как добавлять мобов, предметы, квесты и навыки — см. [docs/09-framework.md](../docs/09-framework.md).
