# 06. Пайплайн ассетов: от бесплатных паков к своим моделям

> Как довести модель природы до игры в нашем стиле (toon-шейдер, палитра леса, экспорт кнопкой, свет): **[10-blender-environment.md](10-blender-environment.md)**.

## Стратегия

1. **Сейчас:** greybox (кубы ProBuilder) → бесплатные лоуполи-паки. Геймплей важнее красоты.
2. **Параллельно:** учимся Blender на простых пропсах (бочка, сундук, камень).
3. **Постепенно:** заменяем ассеты паков своими, начиная с самых простых и самых заметных (лут на земле, пропсы, оружие).
4. **Позже:** свои персонажи и мобы (самое сложное: риг, анимация).

Благодаря связи по `id` (см. архитектуру) замена = подменить префаб/модель в `Visual`-ассете, код и данные не меняются.

## Визуальный стиль (чтобы всё смотрелось единым)

- **Палитра-атлас:** одна текстура-градиент 256×256 с цветными квадратами; UV моделей «попадают» в нужный цвет. Так работают паки KayKit/Synty, и так же будем делать свои модели. Минимум текстур, единый вид.
- **Toon-шейдер** (Shader Graph): 2–3 ступени освещения + rim light + outline (инвертированный hull или пост-эффект). Базовая версия уже есть: `Game/Stylized Toon` (см. 10). Outline — на этапе «полировка».
- **Пост-процесс:** Bloom (умеренно), Color Adjustments, Vignette. Без тяжёлого AO/SSR.
- **Масштаб:** 1 юнит = 1 метр, герой ≈ 1.8 м. Камера сверху под ~50–60°, поэтому важны силуэты и верх моделей, детали внизу не видны.
- **Читаемость:** мобы контрастнее окружения, враждебные эффекты красно-оранжевые, лут подсвечивается цветом редкости.

## Экспорт Blender → Unity

| Настройка | Значение |
|---|---|
| Формат | FBX |
| Масштаб | Apply Scalings: **FBX All**, Scale 1.0 |
| Оси | Forward: **-Z Forward**, Up: **Y Up**, ✔ Apply Transform |
| Что экспортировать | ✔ Selected Objects, Mesh (+ Armature для персонажей) |
| Перед экспортом | Apply All Transforms (Ctrl+A), origin внизу по центру модели |
| Именование | `SM_Barrel_01` (static mesh), `SK_Goblin` (skinned), `M_Atlas` (материал), `T_Atlas_Albedo` (текстура) |
| Куда | `.blend` → `Art/Blender/…`, `.fbx` → `Game/Assets/_Project/Art/Models/…` |

В Unity: Model Import → `Scale Factor 1`, `Convert Units ✔`, отключить `Import Cameras/Lights`, материал заменить на свой с атласом.

## План обучения Blender (по ~2–4 часа в неделю)

| Неделя | Тема | Результат для игры |
|---|---|---|
| 1 | Интерфейс, навигация, режимы, примитивы. Курс: **Blender Guru «Donut»** (первые части) или **Grant Abbitt «Beginner low poly»** | Понимаешь, где что |
| 2 | Edit Mode: extrude, inset, bevel, loop cut | Бочка, ящик, факел |
| 3 | Модификаторы (Mirror, Solidify, Bevel), Shade Flat/Auto Smooth | Сундук, камни, забор |
| 4 | UV-развёртка под палитру-атлас | Все предыдущие пропсы окрашены атласом и в игре |
| 5–6 | Оружие и броня (меч, топор, щит, шлем) | Свои предметы на земле и в руках |
| 7–8 | Модульные куски окружения (стены, пол, углы на сетке 2×2 м) | Своя тема для комнат данжа |
| 9–10 | Лоуполи персонаж (Grant Abbitt / Imphenzia «low poly character») | Модель моба |
| 11–12 | Риг: Rigify или автоматический через **Mixamo** + анимации Mixamo | Свой моб бегает и бьёт в игре |
| дальше | Простая анимация руками, Geometry Nodes для вариаций пропсов | — |

Полезные каналы: **Grant Abbitt**, **Imphenzia** (лоуполи за 10 минут), **Kenney** (стрим-процессы), **CG Fast Track**.

Правило: каждая выученная тема сразу даёт ассет, который попадает в игру. Мотивация не теряется.
