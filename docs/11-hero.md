# Герой: модель, внешность, наруч

Этап 1 из плана «герой и вступление в овраге». Герой — Странник: обычный человек ~22–25 лет,
золотые растрёпанные волосы, гетерохромия (правый глаз золотой — Свет, левый фиолетовый — Тьма),
на старте без одежды (сгорела в атмосфере), только набедренная повязка, иномирный наруч на левом предплечье
и ржавый меч.

## Из чего собран

| Часть | Откуда |
|---|---|
| Тело, риг (Humanoid), глаза, брови | Quaternius **Universal Base Characters** [Standard], модель Superhero_Male, CC0 |
| Анимации | Quaternius **Universal Animation Library** [Standard], `UAL1_Standard.fbx`, CC0 |
| Волосы, повязка, наруч, кристалл, ржавый меч | генерирует `Tools/Blender/hero_build.py` |

Скрипт `hero_build.py`:
* берёт базу и перекрашивает серые «трусы» базы в тёмную ткань-подмотку;
* строит волосы из прядей по форме черепа (крепятся к кости `Head`);
* строит повязку из мешковины с обгоревшим краем и скиннит её на таз/бёдра (веса с тела);
* строит наруч по форме предплечья (кость `lowerarm_l`): гранёный тёмный металл, цвета побежалости на краях,
  гнездо с кристаллом; половины кристалла помечены цветом вершин (R=1 Свет, R=0 Тьма);
* кладёт ржавый меч в правую руку (кость `hand_r`) и отдельно экспортирует его для мира;
* помечает правый/левый глаз цветом вершин, делает маску радужки в альфе `T_Hero_Eyes.png`.

Запуск:
```
blender -b -P Tools/Blender/hero_build.py -- --ubc "<папка Universal Base Characters[Standard]>" --out <папка> --preview hero.png
```
Результат копируется в `Game/Assets/_Project/Art/Models/Characters/Hero/`, анимации — в
`Game/Assets/_Project/Art/Animations/UAL/UAL1_Standard.fbx`.

## В Unity

**Game → Герой → Собрать героя.** Делает:
* материалы `Art/Materials/Characters/M_Hero_*` на шейдере **Game/Character Toon** (тот же toon-свет, что у леса,
  плюс карта нормалей, слой грязи и режим глаз) и **Game/Bracer Crystal**;
* `Art/Animations/AC_Hero.controller`: ходьба/бег по `Speed`, удары `Attack`/`HeavyAttack`
  (скорость подгоняется под длительность умения), `Die`/`Revive`, `PickUp`;
* префаб `Prefabs/Characters/Hero.prefab` с компонентом `HeroAppearance`;
* `Resources/Visuals/AV_Hero.asset` (id `hero`) — после этого `ActorFactory` спавнит героя на новой модели.

Настройки импорта (Humanoid, имена клипов без `Armature|`, петли `*_Loop`, корень без смещения) ставит
`HeroImportRules` автоматически.

## Что крутить без перекомпиляции

`StreamingAssets/Data/characters/hero.json → appearance`, после правки **F5** прямо в игре:

| Поле | Что делает |
|---|---|
| `hairColor`, `browColor`, `skinTint` | цвета волос, бровей, оттенок кожи |
| `eyeRight`, `eyeLeft`, `eyeGlow` | гетерохромия и сила свечения радужки |
| `dirtStart`, `washSeconds`, `dirtColor` | грязь/пепел/царапины после падения и скорость умывания |
| `balance` | кристалл наруча: 0 — Тьма, 0.5 — поровну, 1 — Свет |
| `crystalGlow`, `crystalLight`, `crystalDark` | яркость и цвета половин кристалла |
| `absorbRadius` | с какого расстояния наруч тянет энергию из убитых врагов |
| `weapons`, `defaultWeapon` | какую модель оружия показывать для надетого предмета |

## Команды консоли (~)

* `dirt 0.5` — грязь на коже (без числа — показать текущую);
* `wash` — умыться;
* `balance 0.9` — кристалл в сторону Света (0 — Тьма);
* `absorb 6` — проверить поглощение: искры летят в наруч, кристалл вспыхивает.
