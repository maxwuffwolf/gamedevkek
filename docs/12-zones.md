# Зоны и переходы между ними

Каждая локация (овраг, лес, будущие данжи) — **отдельная сцена Unity**. Переход как в Path of Exile:
кликаешь по арке/двери → экран загрузки → ты в другой зоне, с тем же здоровьем, инвентарём и квестами.

## Как это устроено

```
клик по ZonePortal ─► ZoneService.Travel("forest", "from_ravine")
                         1. экран загрузки плавно закрывает картинку (0.35 с)
                         2. SceneManager.LoadSceneAsync("Showcase") — сцена грузится в фоне,
                            полоса прогресса ползёт (минимум ~1 с, чтобы не мелькало)
                         3. старая сцена выгружается: мобы, лут на земле, камера, свет — уничтожаются
                         4. игрок ставится на ZoneEntrance с Id "from_ravine", камера цепляется к нему
                         5. экран загрузки гаснет, сверху всплывает название зоны
```

**Почему ничего не теряется.** Инвентарь, квесты, уровень, золото — обычные C#-объекты в `Services`, к сцене
они не привязаны. Объекты `[Game]`, `[UI]` и сам **игрок** помечены `DontDestroyOnLoad` — Unity переносит их
в специальную «вечную» сцену, и смена сцены их не трогает. Всё остальное принадлежит сцене и исчезает вместе с ней
(поэтому мобы в зоне каждый раз появляются заново, как в PoE).

**Почему Play работает с любой сцены.** Бутстрап (`GameRoot`) запускается при старте любой сцены. Открыл лес и нажал
Play — появишься в лагере (PlayerSpawnPoint), открыл овраг — в кратере. Ходить через загрузку для теста не обязательно:
`F1` → кнопки «→ Овраг / → Лес», или в консоли (`~`) `zone forest`, `zones`.

## Из чего состоит

| Что | Где | Зачем |
|---|---|---|
| `zones/zones.json` | StreamingAssets/Data | список зон: id, название, имя сцены, подзаголовок и советы для экрана загрузки, цвет фона. Правится на лету (F5) |
| `ZonePortal` | компонент на сцене | объект-переход. Поля: **TargetZone** (id зоны), **TargetEntrance** (куда встать в той сцене) |
| `ZoneEntrance` | компонент на сцене | точка прибытия с **Id**. Синяя рамка со стрелкой в окне Scene = куда игрок встанет и куда посмотрит |
| `PlayerSpawnPoint` | компонент на сцене | старт при Play и «запасной» вход, если Id не нашёлся |
| `ZoneService` | Gameplay/Zones | сама загрузка (корутина) |
| `LoadingScreenView` | UI | только рисует экран загрузки |
| Build Settings | меню **Game → Зоны → Обновить список сцен** | Unity грузит во время игры только сцены из этого списка. Стартовая зона (`"start": true`) — первая |

## Как добавить новый переход (пример: пещера в лесу)

1. **Сцена.** Создай сцену `Cave.unity` в `Assets/_Project/Scenes/` (File → New Scene, или скопируй существующую Ctrl+D).
   Положи в неё землю, камеру с тегом MainCamera, свет и объект с `PlayerSpawnPoint`.
2. **Данные.** Допиши в `zones.json`:
   ```json
   { "id": "cave", "name": "Логово падальщиков", "scene": "Cave", "level": 3,
     "subtitle": "Пахнет сыростью и кровью", "tips": ["В темноте держись ближе к факелам."] }
   ```
3. **Build Settings.** Меню **Game → Зоны → Обновить список сцен (Build Settings)**. В диалоге должно быть `Cave`.
4. **Туда.** В лесу: пустой объект (или модель входа) → Add Component → `ZonePortal`.
   TargetZone = `cave`, TargetEntrance = `from_forest`. Триггер-коллайдер для мыши добавится сам.
5. **Обратно.** В Cave: портал с TargetZone = `forest`, TargetEntrance = `from_cave`, рядом с ним пустой объект с
   `ZoneEntrance`, Id = `from_forest` (тут появится игрок, пришедший из леса).
   В лесу рядом с входом в пещеру — `ZoneEntrance` с Id = `from_cave`.
6. Play → кликни по порталу.

Правило имён: вход называется по тому, **откуда** пришли (`from_forest`), так пары портал↔вход легко читаются.

Быстрая арка со светящейся пеленой есть в редакторе кодом: `ZoneGateBuilder.Build(...)` (так сделаны врата в овраге и лесу).
Потом её можно заменить своей моделью из Blender — компоненты `ZonePortal` и `ZoneEntrance` просто остаются.

## Если что-то не так

- «Сцена X не добавлена в Build Settings» → Game → Зоны → Обновить список сцен.
- «В сцене нет ZoneEntrance с Id …» (в консоли) → опечатка в TargetEntrance или Id. Игрок встанет на PlayerSpawnPoint.
- Портал не подсвечивается при наведении → у объекта нет коллайдера (удали и снова добавь `ZonePortal`).
- `zones` в консоли показывает зоны, текущую зону и входы на открытой сцене.

## Что потом

- Сохранять текущую зону в сейв и продолжать с неё (появится вместе с главным меню).
- Процедурные данжи: та же схема, только сцена-«пустышка», которую генератор заполняет при загрузке.
- Порталы-телепорты (вейпоинты) между открытыми зонами — тот же `ZoneService.Travel`.
