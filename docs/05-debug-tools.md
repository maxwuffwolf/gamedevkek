# 05. Инструменты отладки и экспериментов

Цель: любую идею можно проверить за минуту, не трогая код и не проходя игру заново.
Всё из этого раздела живёт в сборке `Game.DevTools` и компилируется только в редакторе и Development Build.

## 1. Дев-консоль (`~`)

Своя консоль на UI Toolkit/UGUI (без платных ассетов). Регистрация команд атрибутом:

```csharp
public static class CheatCommands
{
    [DevCommand("give", "Выдать предмет: give <id> [rarity] [ilvl]")]
    public static string Give(string id, Rarity rarity = Rarity.Rare, int ilvl = 1) { ... }

    [DevCommand("spawn", "Заспавнить моба под курсором: spawn <id> [count] [lvl=N]")]
    public static void Spawn(string id, int count = 1, int lvl = 0) { ... }
}
```

Возможности: автодополнение команд и `id` контента по Tab, история (↑/↓), вывод `Debug.Log` с фильтром по категориям, выполнение скрипта команд из файла (`exec test_build.txt`).

### Базовый набор команд

| Команда | Что делает |
|---|---|
| `help [cmd]` | Список команд / справка |
| `god` / `noclip` / `oneshot` | Бессмертие / сквозь стены / убийство с одного удара |
| `give <id> [rarity] [ilvl]` | Выдать предмет |
| `give.random <count> [ilvl]` | Пачка случайного лута |
| `spawn <monsterId> [count] [lvl=N] [elite]` | Спавн мобов под курсором |
| `killall` | Убить всех мобов в радиусе |
| `level <n>` / `xp <n>` / `gold <n>` | Уровень, опыт, валюта |
| `stat <StatId> <value>` / `stats` | Задать стат / показать полный лист статов с источниками |
| `timescale <x>` | Замедление/ускорение времени (0.1 для разбора боя) |
| `zone.goto <id>` | Телепорт в зону |
| `dungeon.generate <id> [seed=N]` | Сгенерировать данж |
| `dungeon.debug on/off` | Гизмо графа комнат |
| `loot.roll <baseId> <rarity> <ilvl> [xN]` | Сгенерировать предметы и вывести в лог |
| `loot.sim <tableId> <N>` | Статистика дропа таблицы |
| `data.reload` | Перезагрузить весь JSON-контент |
| `data.validate` | Проверить контент |
| `save` / `load` / `save.wipe` / `save.slot <name>` | Сейвы, включая отдельные тестовые слоты |
| `ai.debug on/off` | Подписи состояний ИИ над мобами |
| `hitbox.show on/off` | Отрисовка хитбоксов |

## 2. Чит-меню (F1)

Панель с кнопками для того, что неудобно печатать: выбор моба из списка + слайдер количества, выдача предмета из списка с фильтром, пресеты билдов («танк 30 ур.», «стеклянная пушка»), переключатели god/noclip/hitboxes.
Пресеты билдов — это JSON-файлы в `StreamingAssets/Data/dev/presets/`: набор предметов + уровень + статы, применяются одной кнопкой.

## 3. Горячая перезагрузка данных (F5)

- `FileSystemWatcher` следит за `StreamingAssets/Data/` (в редакторе и dev-билде).
- При изменении файла: debounce 200 мс → `ContentDatabase.Reload()` → `ContentReloadedEvent`.
- Живые объекты подписаны на событие и переприменяют параметры: мобы пересчитывают статы, лут-таблицы сразу используют новые веса, скиллы новые множители.
- Ошибка парсинга не роняет игру: остаются старые данные, в консоли подсвечивается файл и строка.

Рабочий процесс: игра в одном окне, JSON в редакторе в другом. Сохранил, увидел результат.

## 4. Перезагрузка кода

- **Enter Play Mode Options** без Domain Reload, вход в Play Mode ≈ 1 сек.
- **Assembly definitions**, перекомпилируется только изменённая сборка.
- Опционально **Hot Reload for Unity**: правки методов применяются прямо в Play Mode.

## 5. Сцены-песочницы (`Scenes/Sandbox/`)

| Сцена | Для чего |
|---|---|
| `Combat.unity` | Ровная арена, манекены с HP-баром и DPS-метром, спавн мобов |
| `Loot.unity` | Персонаж + сундук «открыть 100 раз», тестирование фильтра и тултипов |
| `DungeonGen.unity` | Генерация данжа по кнопке, вид сверху, без мобов |
| `RoomWorkshop.unity` | Сборка комнат данжей |
| `Movement.unity` | Полоса препятствий, настройка камеры и управления |

Любая сцена запускается напрямую, сервисы поднимаются авто-бутстрапом (см. архитектуру).

## 6. Оверлеи и визуальная отладка

- **F3: оверлей** FPS, количество мобов, текущий seed, зона/тир, активные модификаторы.
- **DPS-метр** и лог урона (кто, кому, сколько, крит или нет, из каких модификаторов сложилось).
- Гизмо: агро-радиусы, пути NavMesh, хитбоксы атак, сокеты комнат.
- **Тултип с отладкой**: Alt над предметом показывает `id`, ilvl, тиры аффиксов, seed.

## 7. Профилирование

- Unity Profiler + Frame Debugger, когда что-то тормозит.
- `ProfilerMarker` вокруг генерации данжа, генерации лута и пересчёта статов.
