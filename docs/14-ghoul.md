# Падальщик (гуль) — первый враг

Оригинальное существо сумеречного леса: сгорбленный тощий гуль на пальцеходящих ногах, длинные чёрные когти,
пепельно-зелёная шкура, глаза-угольки, трутовики и светящиеся споровые грибы на спине,
трофеи мародёра (набедренник из красного табарда павшего солдата, ожерелье из зубов, тряпки на предплечье).

## Пайплайн

| Шаг | Что | Где |
|---|---|---|
| 1 | Генератор модели, рига и анимаций | `Tools/Blender/ghoul_build.py` |
| 2 | FBX (клипы Idle / Walk / Run / Attack / Hit / Death) | `Game/Assets/_Project/Art/Models/Characters/Monsters/Ghoul/Mon_Ghoul.fbx` |
| 3 | Исходник Blender | `Art/Blender/Characters/ghoul.blend` |
| 4 | Сборка в Unity | меню **Game → Монстры → Собрать падальщика (гуль)** (`Editor/GhoulBuilder.cs`), также при пересборке оврага |

```
python ghoul_build.py --out <папка> --preview ghoul_preview.png --poses ghoul_poses.png
```

Сборка делает материалы `M_Ghoul`, `M_Ghoul_2S` (ткань, уши), `M_Ghoul_Glow` (Character Toon, `_EmissionFromAlbedo`),
контроллер `AC_Ghoul` (Speed: Idle 0 → Walk 1.3 → Run 3.9; Attack растягивается под длительность умения;
Die; аддитивный слой Hit — вздрог поверх бега и удара), префаб `Prefabs/Characters/Mon_Ghoul` и
`Resources/Visuals/AV_Scavenger` (id `scavenger` = `prefab` в `monsters/ravine.json`).

Передвижение ползком на четырёх лапах: корпус низко, локти и колени в стороны, лапы переставляются по диагонали (Walk — крадётся, Run — быстро стелется), без подпрыгиваний. Задние ноги в самой модели укорочены (`LEG_K = 0.72` в ghoul_build.py: кости и вершины ног сжимаются по высоте, корпус опущен), руки разведены в стороны рысканием (yaw), поэтому силуэт широкий и прижатый к земле, как у ползающего лайфстилера. `GROUND_FIX` в режиме contact держит лапы на земле в Walk/Run. Мобы не сталкиваются капсулами друг с другом и мягко расталкиваются (Mover).
Удар — двумя лапами сверху вниз, попадание на 58 % клипа (= `hitFrame` умения `scavenger_slash`).

Смерть: сплайн по ключевым позам (вздрог → колени подкашиваются → падает ничком); корень в Death/Walk/Run
автоматически приподнимается так, чтобы ничего не уходило под землю (`GROUND_FIX` в генераторе). Труп не опрокидывается
и не перекрашивается: лежит, потом рассыпается пеплом с тлеющей кромкой (`CorpseDissolver` + `_Dissolve` в Character Toon).

Бинарники (fbx/blend) идут через Git LFS с ПК Max — из облака LFS не пушится.

## Качество «как в Albion» (2026-11-27)

- `SUBD_LEVEL = 1` в ghoul_build.py включает гладкую версию (0 вернёт старый гранёный low-poly).
- Тело, шея, голова, руки и ноги (`SKIN_PARTS`) сливаются в одну цельную кожу: Катмулл-Кларк ×2 → voxel remesh (`SKIN_VOXEL`) → сглаживание → decimate до `SKIN_TRIS`. Шаров-суставов и стыков больше нет.
- Цвет и веса каждой вершины кожи берутся у ближайшего исходного куска; веса сглажены по соседям.
- `paint_pass`: AO лучами по телу, кривизна (блик на рёбрах, грязь в складках), верхний свет, тёплый отсвет в тенях. Плюс прожилки и тёплый подтон в `skin_col`.
- Остальные куски (кисти, уши, ткань, глаза, грибы) — Катмулл-Кларк ×1 и мягкие нормали; зубы, споры и ожерелье остаются гранёными.
- Итого ~26k треугольников. В Unity у материалов гуля `_StepSmooth = 0.32` — мягкий переход свет/тень.

## Возврат к прямохождению (2026-11-27)

Max решил, что ползание не подходит: Walk/Run снова `gait_pose` (двуногий пальцеходящий шаг), `LEG_K = 1.0` (исходная длина ног). `quad_pose` и `LEG_K` оставлены в генераторе на случай возврата. Гладкая модель, удар двумя лапами, смерть и разведение мобов (Mover) не менялись.
