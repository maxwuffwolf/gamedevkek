## 1. Откуда «вайб» и кто за что отвечает

| Приём | Кто делает |
|---|---|
| Крупные формы, читаемый силуэт сверху, правило трёх размеров | вы, в Blender (гайд) |
| Низ тёмный, верх светлый | палитра-градиент (UV на полосу) **+** шейдер (градиент по высоте) |
| Тёплый свет, холодные **цветные** тени | шейдер (`Shadow tint`) + пост-обработка (Split Toning) |
| Ступенчатый, «нарисованный» свет | шейдер (`Light steps`) |
| Светлый ободок по силуэту | шейдер (`Rim`) |
| Ни одно дерево не похоже на соседнее | шейдер (`Per-instance variation`) + случайный поворот/масштаб |
| Живая листва | шейдер (`Wind`) |

Стандартный `URP/Lit` из гайда — нормальная отправная точка. `Game/Stylized Toon` — следующий шаг: те же модели и та же палитра, но картинка становится заметно ближе к Shape of Dreams / Darksiders Genesis.

## 2. Toon-шейдер `Game/Stylized Toon`

Обычный HLSL-шейдер под URP 17 (Unity 6.6), его можно читать и менять. Поддерживает тени солнца, точечные источники (костёр, факелы — тоже ступенчато), туман, SSAO, SRP Batcher и GPU Instancing.

Цвет пикселя = палитра × Tint × цвет вершин × градиент по высоте × вариация экземпляра, затем toon-свет и rim.

| Параметр | Что делает | С чего начать |
|---|---|---|
| Palette / Tint | текстура (палитра) и общий оттенок | `T_Palette_Forest`, белый |
| Use vertex colors | умножать на цвета вершин из Blender | вкл. (без цветов вершин ничего не меняет) |
| Per-instance variation | случайный сдвиг яркости/оттенка у каждого экземпляра (по позиции в мире) | 0.08 |
| Bottom tint / Top tint / Gradient height | дополнительное затемнение низа модели, высота в метрах | низ `#B8B8CC`, высота ≈ высота модели |
| Shadow tint | цвет теневой стороны | фиолетово-синий `#6B66A0` |
| Light steps / Step softness | число ступеней света и мягкость грани | 2 / 0.06 |
| Ambient strength | сколько света неба попадает в тени | 0.35 |
| Rim color / power / strength | ободок по силуэту | тёплый белый / 3.5 / 0.2 |
| Wind strength / speed / scale | качание верха модели (сила растёт с высотой) | 0 для камней, 0.02–0.05 для деревьев и кустов |

### Материалы

Один шейдер, одна палитра, несколько материалов с разной высотой градиента и ветром
(SRP Batcher рисует их почти так же дёшево, как один):

| Материал | Gradient height | Wind | Для чего |
|---|---|---|---|
| `M_Env_Forest` | 1.5 | 0 | камни, пятна земли, всё неподвижное |
| `M_Env_Forest_Tree` | 5 | 0.03 | деревья |
| `M_Env_Forest_Foliage` | 1 | 0.05 | кусты, трава |

Create → Material → Shader **Game/Stylized Toon** → Palette = `T_Palette_Forest`.
Крутите параметры прямо в Play Mode: материал — ассет, изменения сохраняются после выхода из Play.

Хотите сравнить: поставьте один камень с `URP/Lit`, рядом такой же с `Game/Stylized Toon`.

### Упражнение на потом

Собрать такой же шейдер в Shader Graph, чтобы понять устройство: Custom Function с `GetMainLight` → `Dot(Normal, LightDir)` → Posterize → `Lerp(ShadowColor, 1)` → Multiply на `Sample Texture 2D` × Vertex Color. Разборы: поиск «URP toon shader custom lighting shader graph» (Daniel Ilett, Ned Makes Games, Cyanilux).

## 3. Автонастройки импорта

`ArtImportRules` срабатывает при **первом** импорте файла (ручные правки в инспекторе потом не перетираются):

- `Art/Textures/**/*Palette*` — Filter Bilinear, без мипмапов, без сжатия, Clamp. Ровно то, что гайд просит выставить руками: цвета соседних полос не «протекают».
- `Art/Models/**` — Scale 1, без камер и света из Blender, без анимации, Material Creation Mode = **None** (материал `M_Env_*` ставим сами на префаб; шаг с Remapped Materials из гайда не нужен).

Если файл уже импортирован раньше: ПКМ → Reimport не поможет (настройки уже есть), выставьте руками или удалите `.meta` рядом с файлом и вернитесь в Unity.

## 4. Экспорт из Blender одной кнопкой

Ручной экспорт с пресетом из гайда работает. Кнопка удобнее, когда моделей много:

1. Blender → вкладка **Scripting** → Open → `Tools/Blender/export_to_unity.py` → **Run Script**.
   Чтобы панель была всегда: Edit → Preferences → Add-ons → ▾ → **Install from Disk** → тот же файл → включить.
2. `.blend` сохранён внутри клона репозитория (например `Art/Blender/Environment/Forest/`).
3. 3D-вид → `N` → вкладка **Unity** → Папка `Environment/Forest` → выделить модели → **Export selected**.

Каждый выделенный меш уходит отдельным `Game/Assets/_Project/Art/Models/<папка>/<имя объекта>.fbx`
с настройками из 06 (FBX All, −Z Forward, Y Up, Apply Transform, Smoothing Face, цвета вершин sRGB).
Объект на время экспорта ставится в (0,0,0), так что можно держать все камни рядом в одной сцене — в Unity они всё равно придут с origin в нуле.
Ctrl+A → All Transforms перед экспортом по-прежнему нужен.

## 5. Дополнительный приём: цвета вершин

Гайд красит всё через палитру. Второй инструмент — **Vertex Paint** в Blender, шейдер его понимает:

- **Пятна на земле и накладках:** вместо отдельной полосы — мягкие переходы трава → тропа прямо кистью.
- **Быстрая вариация:** копия куста, Vertex Paint → Paint → Set Vertex Colors светло-жёлтым на верхушке — «осенний» вариант без новой полосы в палитре.
- Цвет вершин **умножается** на палитру: белый = без изменений. Красьте светлыми оттенками.

Экспорт: Vertex Colors = **sRGB** (кнопка делает это сама); шейдер переводит их в Linear, иначе цвета выцветают.

## 6. Свет и пост-обработка

Сцена Showcase уже ставит тёплое солнце, трёхцветный ambient и туман. Для «вайба» добавьте:

1. Hierarchy → Create → Volume → **Global Volume** → Profile **New** → Add Override:
   - **Tonemapping:** Neutral;
   - **Color Adjustments:** Post Exposure 0.1–0.2, Saturation +15…+25, Contrast +10;
   - **Split Toning:** тени — синий/фиолетовый, света — оранжевый, Balance ≈ −20 (самый «живописный» эффект);
   - **Bloom:** Threshold 1, Intensity 0.3–0.5;
   - **Vignette:** 0.2.
2. Main Camera → Rendering → ✔ **Post Processing**, иначе Volume не действует.

Так как сцену пересобирает генератор, сохраните профиль Volume как ассет в `Art/` — потом добавим его в генератор.

## 7. Типичные ошибки

| Симптом в Unity | Причина | Лечение |
|---|---|---|
| Модель лежит на боку / повёрнута на −90° | трансформы не применены или неверные оси | `Ctrl+A` → All Transforms; экспорт кнопкой |
| Модель в 100 раз больше/меньше | Apply Scalings не FBX All | экспорт кнопкой |
| Висит над землёй / утонула | origin не внизу | origin внизу по центру, низ на Z=0 |
| Дыры, невидимые грани | вывернуты нормали | Blender: Overlays → Face Orientation (красное = плохо), `Shift+N` |
| Цвет «плывёт» на соседнюю полосу | мипмапы/сжатие или UV на границе полосы | автонастройки из п. 3; столбик UV — в середину полосы |
| Цвета блёклые | цвета вершин без перевода sRGB → Linear | использовать `Game/Stylized Toon` |
| Розовая модель | не URP-материал | `M_Env_*` |
| Всё слишком тёмное с toon-шейдером | мало ambient или тёмный Shadow tint | Ambient strength ↑, Shadow tint светлее |
| Тень «рябит» полосами на земле | слишком маленький Step softness | 0.05–0.1 |
