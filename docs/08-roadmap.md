# 08. Роадмап

Темп хобби: условно 6–10 часов в неделю. Сроки ориентировочные, это не дедлайны.
Каждый этап заканчивается **чем-то играбельным** и тегом в git.

---

## Этап 0. Фундамент (1 неделя)

- [ ] Установить Unity 6 LTS, Rider/VS, Git LFS, Blender.
- [ ] Создать Unity-проект в `Game/` (шаблон Universal 3D), настройки из [02](02-tech-stack.md).
- [ ] Поставить пакеты: Input System, Cinemachine, AI Navigation, Newtonsoft Json, ProBuilder, UniTask, DOTween.
- [ ] Структура папок и assembly definitions из [03](03-architecture.md).
- [ ] `Services`, `EventBus`, `Log`, авто-бутстрап сцены.
- [ ] Каркас дев-консоли с командами `help`, `timescale`.
- [ ] Первый коммит Unity-проекта, тег `m0-foundation`.

**Готово, когда:** открывается пустая сцена, `~` открывает консоль.

## Этап 1. Движение и бой (2–3 недели)

- [ ] Персонаж (капсула → модель из Quaternius/KayKit): WASD, поворот к курсору, dash (Space).
- [ ] Cinemachine top-down камера с лёгким опережением в сторону курсора.
- [ ] `StatSheet` + модификаторы.
- [ ] `Health`, `DamageCalculator`, базовая атака по ЛКМ (хитбокс по анимации).
- [ ] Манекен с HP-баром, цифры урона.
- [ ] Hit feedback: hit-stop, тряска, вспышка.
- [ ] Команды `god`, `oneshot`, `stat`, `stats`, `hitbox.show`.
- [ ] Сцены `Sandbox/Movement`, `Sandbox/Combat`.

**Готово, когда:** приятно бегать и бить манекен. Тег `m1-movement-combat`.

## Этап 2. Мобы (2 недели)

- [ ] `ContentDatabase` + загрузка `monsters/*.json` + hot reload (F5 / FileSystemWatcher).
- [ ] `MonsterActor`, FSM ИИ (`melee_basic`, `ranged_kiter`).
- [ ] 2–3 моба из бесплатных паков (гоблин-ближник, лучник, толстяк).
- [ ] Смерть, опыт, уровень персонажа.
- [ ] Команды `spawn`, `killall`, `ai.debug`, `data.reload`.

**Готово, когда:** арена с волнами мобов, баланс правится в JSON на лету. Тег `m2-monsters`.

## Этап 3. Лут (2–3 недели) — сердце игры

- [ ] Определения: базы предметов, аффиксы, лут-таблицы (JSON).
- [ ] Генератор предметов (редкость, ilvl, тиры аффиксов, seed).
- [ ] Предметы на земле с подсветкой редкости и подписью, подбор по клику.
- [ ] Инвентарь (сетка или список) и экипировка по слотам → модификаторы в `StatSheet`.
- [ ] Тултипы с аффиксами и сравнением с надетым.
- [ ] Команды `give`, `loot.roll`, `loot.sim`.

**Готово, когда:** убиваешь мобов → падает лут → надеваешь → бьёшь сильнее. **Это первый играбельный core loop.** Тег `m3-loot`.

## Этап 4. Мир и сохранения (2 недели)

- [ ] Сцена-хаб (тайник, портал в зону).
- [ ] Одна открытая зона (блок-аут ProBuilder + ассеты KayKit), `SpawnArea`, респавн пачек.
- [ ] Переходы между сценами.
- [ ] Сохранение/загрузка (персонаж, инвентарь, тайник), версия сейва.
- [ ] Тайник в хабе.

**Готово, когда:** можно выйти из игры, зайти и продолжить фармить. Тег `m4-world-save`.

## Этап 5. Процедурный данж (3 недели)

- [ ] 6–10 комнат-префабов в одной теме (KayKit Dungeon).
- [ ] Генератор графа комнат по seed, стыковка по сокетам, рантайм NavMesh.
- [ ] Спавн пачек по комнатам, элитные мобы с 1–2 аффиксами.
- [ ] Босс в конце (увеличенный моб с 2–3 атаками).
- [ ] Вход из открытой зоны, выход в хаб, штраф за смерть.
- [ ] Модификаторы данжа (2–3 штуки).
- [ ] Команды `dungeon.generate`, `dungeon.debug`.

**Готово, когда:** «ещё один заход» хочется сделать самому. Тег `m5-dungeon`. 🎉 **Первый играбельный прототип.**

## После прототипа (порядок по желанию)

- **Скиллы:** 6–8 активных скиллов, слоты на клавишах 1–4 / ПКМ.
- **Пассивное дерево** или система талантов.
- **Тиры мира / сложность:** растущий уровень мобов и ilvl.
- **Уникальные предметы** со свойствами, меняющими механику.
- **Крафт:** валюты-орбы для перероллa аффиксов.
- **Фильтр лута.**
- **Статус-эффекты:** горение, яд, заморозка, стан.
- **Полировка визуала:** toon-шейдер, outline, VFX, звук.
- **Свои модели** по плану из [06](06-art-pipeline.md): сначала пропсы и оружие, потом мобы.
- **Второй биом** и вторая тема данжей.

## Как работать с роадмапом

- Задачи текущего этапа переносить в GitHub Issues с milestone этапа.
- Если какая-то задача надоела, переключиться на другую из того же этапа или на арт. Хобби не должно превращаться в работу.
- Идеи, которые приходят в процессе, записывать в Issues с меткой `idea`, а не делать сразу.
