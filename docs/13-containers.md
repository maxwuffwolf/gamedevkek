# Контейнеры: сундуки, трупы, «меч в земле»

Один шаблон на всё, что открывается окном с вещами: ржавый меч у скелета в овраге, сундуки, обыскиваемые
трупы, тайники. Клик по объекту → герой подходит → слева окно контейнера, справа сам открывается инвентарь.

## Как это устроено

| Что | Где |
|---|---|
| Шаблоны (имя, что внутри, поведение) | `StreamingAssets/Data/containers/containers.json` |
| Объект в сцене | компонент `WorldContainer` (`Gameplay/Items/WorldContainer.cs`) |
| Содержимое, взять/положить, сейв | `ContainerService` (`Gameplay/Items/ContainerService.cs`) |
| Окно | `ContainerView` (`UI/ContainerView.cs`) |

Содержимое **генерируется при первом открытии** (гарантированные `items` + бросок `lootTable` + `gold`)
и дальше живёт в сейве (`SaveData.Containers`, версия сейва 2). Поэтому забранный меч не появится снова
после перезахода в зону. `"persistent": false` — содержимое забывается при уходе из зоны (для «респавнящихся» ящиков).

### Поля шаблона

```json
{
  "id": "chest_small",          // это пишется в WorldContainer.ContainerId
  "name": "Старый сундук",      // подпись при наведении
  "title": "…",                 // заголовок окна (по умолчанию = name)
  "action": "Открыть",          // «ЛКМ — Открыть»
  "description": "…",           // строка курсивом в окне
  "slots": 8,                   // ячеек в окне (по 4 в ряд)
  "items": [ { "id": "sword_rusty", "rarity": "common", "amount": 1, "chance": 1.0 } ],
  "lootTable": "wolf",          // необязательно, бросается вдобавок к items
  "itemLevel": 0,               // 0 = уровень зоны
  "gold": [5, 20],              // забирается сразу при открытии
  "whenEmpty": "Keep",          // Keep — остаётся (можно открыть пустым), Disable — гаснет, Hide — пропадает
  "persistent": true,
  "allowPut": true              // можно класть свои вещи (сундук-хранилище)
}
```

### Управление в окне

* **ПКМ** по вещи в контейнере — взять в рюкзак; **«Взять всё»** — забрать всё.
* Перетащить из контейнера в ячейку рюкзака или **прямо на слот экипировки** (надеть сразу).
* Если `allowPut` — ПКМ по вещи в рюкзаке кладёт её в контейнер, перетаскивание тоже работает.
* Закрыть: `×`, `Esc` или просто отойти.

## Как поставить сундук руками

1. Модель сундука в сцену → **Add Component → WorldContainer**.
2. `Container Id` = `chest_small` (или свой id из JSON). Коллайдер-триггер для клика добавится сам.
3. Если в сцене несколько одинаковых сундуков — впиши каждому свой `Instance Id` (это ключ в сейве).
4. Необязательно: `Hide When Empty` (что пропадает, когда всё забрали), `Show/Hide When Opened` (крышка).

## Ржавый меч в овраге

* Шаблон `ravine_rusty_sword`: внутри один `sword_rusty`, `whenEmpty: Hide` — забрал, и меч исчезает из земли вместе с бликом.
* По сюжету герой начинает **без оружия**: меч убран из `startingItems` в `characters/hero.json`.
* Сцену ставит `RavineSceneBuilder` (меню **Game → Зоны → Пересобрать сцену Овраг**): скелет `Skeleton_Soldier`
  (Environment) и `Container_RustySword` (Gameplay).

## Модели

`Tools/Blender/ravine_props.py` (общие кирпичики и сам меч — `Tools/Blender/lowpoly_kit.py`):

* `Prop_Skeleton_Soldier.fbx` → `Game/Assets/_Project/Art/Models/Props/Ravine/` — павший солдат (~3k треугольников):
  шлем-спангенхельм съехал на глаза, кольчуга, ржавый нагрудник со стрелами, табард, наплечник, сапоги, плащ, расколотый щит.
  Материалы `M_Prop_Ravine` / `M_Prop_Ravine_2S` подменяются в Unity на toon с цветом вершин (`Editor/PropModels.cs`).
* `Wpn_Sword_Rusty.fbx` → `…/Characters/Hero/` — детальный меч (~600 треугольников): дол, сколы, изогнутая гарда,
  обмотка, дисковое навершие. Тот же меч у героя в руке: `--hero hero.blend` переэкспортирует `Hero.fbx` с новым мечом.

```
python ravine_props.py --out <папка> --hero Art/Blender/Characters/hero.blend --preview ravine_props.png
```

## Консоль (~)

* `container.list` — контейнеры на сцене и их состояние (ключи для reset).
* `container.reset [ключ]` — вернуть содержимое по JSON (без ключа — все). После правки JSON: F5 + reset.
* `container.open` — телепорт к ближайшему контейнеру и открыть.
* `save.wipe` — новая игра (контейнеры тоже сбрасываются).
